## 1. 快速开始

### 1.1 系统简介

**Atlas** 是一款轻量级的团队项目管理 Web 应用,覆盖"看板与任务面板 / 进度跟踪与统计 / 项目与任务管理 / 团队协作与权限"四大核心模块,内置通知中心和完整的权限体系。

### 1.2 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端 | React 18 · Vite · TailwindCSS · Zustand · dnd-kit · Recharts |
| 后端 | Express 4 · better-sqlite3 · JWT · bcrypt · zod · multer · nodemailer |
| 数据库 | SQLite (本地文件存储 `data/app.db`) |
| 文件存储 | 本地磁盘 `data/uploads/`(任务附件) |

### 1.3 启动系统

```bash
# 安装依赖(首次运行)
npm install

# 同时启动前端与后端开发服务
npm run dev

# 或者分别启动
npm run server:dev     # 后端 API:http://localhost:3001
npm run client:dev     # 前端 Web:http://localhost:5173
```

打开浏览器访问 `http://localhost:5173` 即可使用。

## 2. 登录与账号

### 2.1 登录

1. 打开系统登录页,默认为"登录"标签。
2. 输入邮箱和密码。
3. 点击 **"登录系统"** 按钮进入系统。

### 2.2 注册新账号

1. 在登录页点击顶部 **"注 册"** 标签。
2. 填写昵称、邮箱、密码(密码明文传输,建议使用强密码)。
3. 点击 **"创建账号"** 完成注册。

新注册的账号默认角色为 **团队成员(member)**,由系统管理员在"团队"页面调整权限。

### 2.3 退出登录

点击右上角头像旁的 **退出图标**,即可安全退出当前会话。

## 3. 系统概览 · 仪表板

登录后首先进入仪表板页面,提供全局视角的数据概览。

### 3.1 顶部欢迎区

显示当前用户的昵称首字 + 待办任务数量,点击 **"打开项目"** 可快速跳转至项目列表。

### 3.2 概览卡片

四个核心指标一目了然:

| 卡片 | 说明 |
| --- | --- |
| 进行中项目 | 状态为"进行中"的项目总数 |
| 任务总量 | 所有项目下的任务总数 |
| 已完成项目 | 状态为"已完成"的项目总数 |
| 逾期项目 | 已超过截止日期但未完成的项目数 |

### 3.3 任务状态分布(环形图)

展示四种状态的任务占比:

- 🟣 **待办** (todo)
- 🟡 **进行中** (in_progress)

- 🟢 **已完成** (done)

### 3.4 14 天任务趋势

面积图展示近 14 天"新建任务"与"完成任务"的时间趋势,帮助团队感知节奏变化。

### 3.5 我的待办任务

列出当前用户名下所有未完成任务(最多 8 条),点击可直接跳转到对应项目。

## 4. 项目管理

### 4.1 进入项目列表

点击左侧导航栏 **"项目"** 进入项目列表页。

### 4.2 搜索与筛选

- **搜索框**:按项目名称或描述中的关键词过滤。
- **状态筛选**:切换标签可快速筛选"全部 / 进行中 / 已完成"。

### 4.3 创建新项目

1. 点击右上角 **"新建项目"** 按钮。
2. 在弹窗中填写:
   - **项目名称**(必填)
   - **项目描述**
   - **项目状态**:规划中 / 进行中 / 已完成 / 已归档
   - **截止日期**
   - **项目负责人**(仅系统管理员可见):可从团队成员中指定负责人;不选则默认为创建者。指定后,该负责人会自动加入项目成员。
3. 提交后,新项目会出现在列表中。

> 💡 普通成员创建项目时不会看到"负责人"选项,默认自己为负责人。

### 4.4 项目卡片

每个项目卡片展示:

- 项目状态徽章
- 项目名称与描述
- **进度条**(自动根据任务完成度计算)
- 项目成员头像堆叠
- 截止日期

点击卡片进入项目详情页。

### 4.5 编辑项目

在项目详情页点击 **"编辑项目"** 按钮,可修改项目信息(名称、描述、状态、截止日期)。

## 5. 项目详情 · 看板与任务

进入项目后,默认显示看板视图。

### 5.1 页面结构

- **顶部区域**:项目名称、状态徽章、描述、进度条、任务数量
- **操作按钮**:导出任务(CSV)、导出进度(Excel)、编辑项目、新建任务
- **工具栏**:搜索框 + 视图切换(列表/看板/**甘特图**) + 批量操作入口(列表视图)
- **主区域**:任务展示区

### 5.2 甘特图视图

点击工具栏的甘特图图标切换到甘特图视图,以时间线方式展示项目任务。

#### 5.2.1 甘特图核心概念

| 元素 | 说明 |
| --- | --- |
| 任务条 | 水平长条表示任务,长度对应起止日期跨度,深蓝填充表示已完成进度 |
| 依赖线 | 任务间的贝塞尔曲线箭头,表示前后依赖关系(FS/SS/FF/SF) |
| 关键路径 | 红色边框标注的任务,决定项目最短工期,拖动物会影响整体进度 |
| 泳道 | 按负责人分组的行,可折叠/展开 |
| 日期轴 | 顶部显示日期刻度,支持日/周/月三级缩放 |

#### 5.2.2 拖拽调整进度

1. 将鼠标悬停到任务条 **右侧边缘**
2. 光标变为 `col-resize` 样式
3. 按住鼠标 **左右拖动**,实时调整完成百分比
4. 松开鼠标后进度自动保存

#### 5.2.3 拖拽调整任务时间

1. 将鼠标悬停到任务条 **主体** 区域
2. 按住鼠标拖动,改变开始日期和截止日期
3. 拖拽时自动吸附到最近的时间刻度(对齐精度)

#### 5.2.4 依赖关系

- **FS**(Finish-to-Start):前序完成后,后序才能开始
- **SS**(Start-to-Start):前序开始后,后序才能开始
- **FF**(Finish-to-Finish):前序完成后,后序才能完成
- **SF**(Start-to-Finish):前序开始后,后序才能完成

点击任务条左侧的 **依赖手柄** 并拖到目标任务上即可建立依赖关系。

#### 5.2.5 键盘快捷键(甘特图)

| 操作 | 快捷键 |
| --- | --- |
| 放大时间线 | `+` 或 `=` |
| 缩小时间线 | `-` |
| 回到今天 | `D` |
| 切换负责人分组 | `G` |
| 取消选择/依赖连接 | `Esc` |
| 搜索任务 | `/` 或点击搜索框 |

#### 5.2.6 过滤与分组

- **搜索**:工具栏搜索框输入关键词,按任务标题/描述过滤
- **负责人分组**:切换泳道模式,按负责人折叠/展开分组
- **筛选**:通过负责人、状态、标签等维度筛选任务

看板将任务按状态分成四列:

| 列名 | 说明 |
| --- | --- |
| 待办 | 尚未开始的任务 |
| 进行中 | 正在执行的任务 |
| 审核中 | 等待审核或验收 |
| 已完成 | 已完成的任务 |

#### 5.2.1 拖拽更新状态

直接用鼠标按住任务卡片,拖拽到目标列,松开即可完成状态更新,系统会自动同步到后端。

> 💡 **小技巧**:鼠标移动超过 5px 才会触发拖拽,避免误操作。

#### 5.2.2 在指定列新建任务

点击某列标题旁的 **"+"** 按钮,会自动将新建任务的预设状态设为该列对应的状态。

#### 5.2.3 看板卡片信息

每张任务卡片显示:
- 任务标题
- 标签 (如有)
- 优先级徽章
- 截止日期(逾期显示红色,即将到期显示黄色)
- 悬停时显示 **编辑** / **删除** 按钮

### 5.3 列表视图

点击工具栏的列表图标切换到表格视图:

- 表格列:选择框 | 任务 | 状态 | 优先级 | 截止 | 操作
- 点击行任意位置 → 打开任务详情抽屉
- 点击行内的编辑/删除图标 → 编辑或删除任务
- 可按状态(全部/待办/进行中/审核中/已完成)快速筛选

#### 5.3.1 批量操作

列表视图支持多选批量操作,大幅提升管理效率:

1. 点击工具栏 **"批量操作"** 按钮进入多选模式。
2. 勾选需要操作的任务(或点击表头全选)。
3. 在底部批量工具栏选择操作:
   - **批量改状态**:一键将选中任务改为待办/进行中/审核中/已完成
   - **批量改负责人**:从下拉菜单选择新负责人
   - **批量删除**:确认后删除所有选中任务
4. 操作完成后显示成功数量,并自动退出多选模式。

> ⚠️ 批量删除不可恢复,请谨慎操作。

### 5.4 新建任务

1. 点击 **"新建任务"** 按钮。
2. 若已有任务模板,对话框顶部会显示 **"从模板创建"** 区域:
   - 从下拉菜单选择模板,自动填充标题、描述、优先级、标签
   - 也可点击模板旁的删除图标移除不再需要的模板
3. 填写任务信息:
   - **任务标题**(必填,最多 120 字符,超长会实时提示)
   - **任务描述**
   - **状态**:待办 / 进行中 / 审核中 / 已完成
   - **优先级**:低 / 中 / 高 / 紧急
   - **负责人**:从团队成员中选择
   - **标签**:多个标签,如"设计"、"后端"、"前端"等
   - **开始日期** / **截止日期**(截止日期不能早于开始日期,会实时校验)
   - **计划工时**(小时)
4. 提交后,任务会出现在看板、列表或甘特图中。

> 💡 可在对话框底部点击 **"保存为模板"**,将当前任务配置保存为模板,下次创建任务时快速复用。

### 5.5 编辑与删除任务

- 悬停任务卡片 → 点击 **铅笔图标** 编辑
- 点击 **垃圾桶图标** 编辑
- 列表视图中操作相同

## 6. 任务详情 · 子任务 · 评论 · 附件

点击任务卡片/行,右侧弹出 **任务详情抽屉**。

### 6.1 基本信息

- **状态徽章** + **优先级徽章**
- 任务标题、描述
- 截止日期(含逾期/即将到期标记)
- 优先级
- 标签列表
- **完成进度**(0-100%,可在甘特图中拖拽调整,或在任务详情中直接编辑)
- **操作历史**(最近 20 条变更记录:创建、状态变更、负责人变更、进度更新、日期变更)

### 6.2 附件管理

任务支持上传文件附件,方便团队共享资料。

#### 6.2.1 上传附件

1. 在"附件"区域点击 **"上传"** 按钮。
2. 选择一个或多个文件(单个文件最大 20MB)。
3. 上传完成后,附件自动显示在列表中。

> 支持所有文件类型:图片、文档、代码、压缩包等。

#### 6.2.2 查看与下载附件

附件列表显示:
- 文件类型图标(图片/文档/代码等不同样式)
- 原始文件名
- 文件大小、上传者、上传时间
- 点击 **下载图标** 可下载原文件

#### 6.2.3 删除附件

鼠标悬停附件条目,点击右侧的 **垃圾桶图标** 即可删除。上传者本人或系统管理员/项目负责人有权删除。

### 6.3 子任务(检查清单)

子任务用于将大任务拆分为可追踪的小步骤。

#### 6.3.1 添加子任务

1. 在"子任务"区域的输入框中输入内容。
2. 按 **回车** 或点击 **"+"** 按钮确认。

#### 6.3.2 完成子任务

点击子任务左侧的 **方框** 即可勾选/取消。完成进度会实时更新:
- 标题旁显示 `(已完成数/总数)`
- 进度条显示完成百分比

#### 6.3.3 删除子任务

鼠标悬停子任务条目,右侧出现 **垃圾桶图标**,点击即可删除。

### 6.4 评论区

#### 6.4.1 查看评论

评论列表按时间顺序展示,包含:
- 评论者头像与昵称
- 评论时间(相对时间,如"5 分钟前")
- 评论内容
- 系统消息以虚线框 + 斜体样式展示(如状态变更记录)

#### 6.4.2 @提及功能

在评论中可以 @提及团队成员,被提及者会收到通知:

1. 在评论输入框中输入 **`@`** 字符。
2. 系统自动弹出成员选择面板,显示匹配的成员。
3. 使用键盘快捷键操作:
   - **↑ / ↓**:在候选列表中上下选择
   - **Enter / Tab**:确认选择当前成员
   - **Esc**:关闭选择面板
4. 也可以用鼠标点击候选成员。
5. 被提及的用户名会以 `@用户名` 格式插入评论,发表后被提及者收到通知。

> 💡 @提及在评论中会高亮显示为品牌色。

#### 6.4.3 发表评论

在底部输入框填写内容,点击 **"发表评论"** 按钮。系统会自动解析其中的 @提及并通知对应成员。

### 6.5 删除任务

在抽屉底部点击 **"删除任务"** 按钮,确认后任务将被永久删除(关联的附件、评论、子任务一并删除)。

## 7. 任务模板管理

任务模板用于预定义任务的标准配置(标题、描述、优先级、标签),适合重复性工作场景(如 Bug 修复、需求评审、发布流程等),可大幅减少重复输入。

### 7.1 创建模板

有两种方式创建模板:

**方式一:从新建任务对话框保存**
1. 点击"新建任务"打开对话框。
2. 在对话框底部点击 **"保存为模板,下次快速创建"**。
3. 输入模板名称(必填)。
4. 点击 **"保存"** 按钮,当前填写的标题、描述、优先级、标签会被保存为模板。

**方式二:直接填写后保存**
1. 在新建任务对话框中填写所需字段。
2. 点击底部"保存为模板"区域。
3. 输入模板名称并保存。

### 7.2 使用模板创建任务

1. 点击"新建任务"打开对话框。
2. 若已有模板,对话框顶部会显示 **"从模板创建"** 区域。
3. 从下拉菜单选择模板,系统自动填充:
   - 任务标题
   - 任务描述
   - 优先级
   - 标签
4. 可在填充基础上继续修改,补充负责人、截止日期等信息。
5. 提交保存即可。

### 7.3 删除模板

1. 在新建任务对话框的"从模板创建"区域选择要删除的模板。
2. 点击模板下拉框旁的 **垃圾桶图标**。
3. 确认后模板被删除(已用该模板创建的任务不受影响)。

> 💡 模板对所有用户共享,任何登录用户都可创建和使用模板。

## 8. 预算与支出管理

预算管理帮助项目团队规划和控制项目成本,支持预算审批流程和支出登记。

### 8.1 预算面板入口

在项目详情页点击 **"预算"** 标签页或滚动到预算区域,即可查看和管理项目预算。

### 8.2 预算类别

系统支持五种预算类别:

| 类别 | 英文 | 说明 |
| --- | --- | --- |
| 人工成本 | labor | 团队成员薪酬成本 |
| 外包费用 | outsource | 外包人员费用 |
| 硬件采购 | hardware | 设备、服务器等 |
| 软件采购 | software | 软件 licenses 等 |
| 其他支出 | other | 杂项支出 |

### 8.3 创建预算

1. 在预算面板点击 **"添加预算"** 按钮。
2. 在弹窗中填写:
   - **预算类别**(必填):从五种类别中选择
   - **预算金额**(必填):必须大于 0,单位 RMB(¥)
   - **备注说明**:可选,描述预算用途
3. 提交后,新建预算的状态为 **"待审批"**。

> ⚠️ **权限说明**:项目成员可创建预算,但需管理员或财务审批后才能生效。

### 8.4 预算审批

**仅系统管理员和财务人员可审批预算**:

1. 进入预算面板,找到状态为"待审批"的预算项。
2. 点击 **"审批"** 按钮:
   - **批准**:点击"批准"确认,预算状态变为"已批准"
   - **驳回**:点击"驳回",填写驳回原因(可选),预算状态变为"已驳回"
3. 已批准的预算会显示在预算汇总中,可用于支出登记。

> ⚠️ 已审批的预算无法修改或删除。

### 8.5 查看预算汇总

预算面板顶部显示预算汇总:
- **总预算**:所有已批准预算的总额
- **已使用**:已登记支出的总额
- **剩余预算**:总预算 - 已使用
- 各类别预算占比分布图

### 8.6 登记支出

1. 在预算面板点击 **"登记支出"** 按钮。
2. 填写支出信息:
   - **关联预算**:选择对应的已批准预算项(可选)
   - **支出类别**:与预算类别对应
   - **支出金额**(必填)
   - **支出日期**(必填)
   - **备注说明**:可选
3. 提交后,支出实时计入项目成本统计。

### 8.7 成本统计

系统会自动汇总项目成本数据:
- 按类别展示预算 vs 支出对比
- 按成员展示工时成本(基于时薪计算)
- 剩余预算预警(支出接近预算时高亮提醒)

> 💡 成本数据在"统计"页面的项目成本报表中也可查看。

## 9. 工时管理

工时管理用于记录和追踪项目中每个任务的工时投入。

### 9.1 任务工时登记

在任务详情抽屉的 **"工时"** 区域可以登记工时:

1. 进入任务详情,滚动到"工时"区域。
2. 点击 **"添加工时记录"** 按钮。
3. 填写:
   - **日期**:工时发生的日期
   - **计划工时**:预计耗时(小时)
   - **实际工时**:实际耗时(小时)
   - **备注**:可选说明
4. 提交后,工时记录显示在列表中。

### 9.2 工时报表

点击导航栏 **"工时报表"** 进入工时统计页面:

- **按用户汇总**:每个用户在各项目上的工时统计
- **按项目汇总**:每个项目的工时投入情况
- **时间筛选**:支持按日期范围筛选
- **成本计算**:根据成员时薪自动计算工时成本

### 9.3 成员时薪设置

**仅系统管理员可设置成员时薪**:

1. 进入 **"团队"** 页面。
2. 找到目标成员,点击编辑按钮。
3. 设置:
   - **是否外包**:标记为外包人员
   - **时薪**:每小时费率(RMB)
   - **成本中心**:成本归属部门
   - **人员类别**:从预设类别中选择(可在团队页面管理类别)
4. 保存后,工时成本会自动计算。

### 9.4 人员类别管理

在团队页面可以管理人员类别:
- 创建自定义类别(如"前端开发"、"后端开发"、"测试"等)
- 设置类别默认时薪
- 标记类别是否为外包

## 12. 通知中心 · 邮件通知

### 12.1 通知入口

顶栏右侧的 **铃铛图标**,带红色徽章显示未读数量。点击铃铛可打开下拉面板快速查看;点击"查看全部"可进入 **通知历史页**。

### 12.2 通知下拉面板(快捷查看)

点击铃铛图标打开下拉面板,展示最近通知:

- 通知类型:分配任务、状态变更、评论(@提及)、系统消息
- 通知标题与正文
- 已读 / 未读状态(未读加粗显示)
- 点击单条通知可标记已读并跳转至关联项目

### 12.3 通知历史页(完整记录)

点击下拉面板中的"查看全部"或直接访问 `/notifications` 进入独立的通知历史页,功能包括:

- **类型筛选**:顶部标签切换"全部 / 分配 / 状态 / 评论 / 系统",每个标签显示对应数量
- **批量操作**:"全部已读"一键标记所有未读通知
- **单条操作**:标记已读、删除通知
- **跳转**:点击通知项可跳转到关联的项目或任务

- **单条标记**:点击通知项右侧的对勾图标

在通知历史页,鼠标悬停通知项,点击右侧的 **垃圾桶图标** 即可删除。

### 12.6 邮件通知

当任务状态变更为 **"已完成"** 时,系统会自动给任务负责人发送邮件通知(需配置 SMTP)。

- 邮件内容包含:项目名称、任务标题、完成提醒
- 采用精美 HTML 模板,品牌色渐变头部
- 仅当负责人不是操作者本人时发送
- 未配置 SMTP 时自动跳过,不影响系统其他功能

> 💡 邮件配置详见 [18.4 邮件配置](#184-邮件配置-smtp)。

### 12.7 触发通知的场景

| 场景 | 通知类型 | 接收者 |

## 13. 数据导出

系统支持将项目与任务数据导出为 CSV 文件,方便数据分析、汇报与备份。

### 13.1 导出项目列表

1. 进入 **"项目"** 页面。
2. 点击右上角 **"导出 CSV"** 按钮。
3. 浏览器自动下载 `projects.csv` 文件。

**导出字段**:项目 ID、名称、描述、状态、进度、成员数、任务数、截止日期、创建时间。

### 13.2 导出项目任务

1. 进入某个项目的 **详情页**。
2. 点击右上角 **"导出任务"** 按钮。
3. 浏览器自动下载 `tasks_<项目ID>.csv` 文件。

**导出字段**:任务 ID、标题、状态、优先级、负责人、标签、截止日期、创建时间。

### 13.3 导出项目进度(Excel)

1. 进入某个项目的 **详情页**。
2. 点击右上角 **"导出进度"** 按钮。
3. 浏览器自动下载 `progress_<项目ID>.xlsx` 文件。

**导出内容**:包含项目下所有任务的甘特图视图,展示任务时间条与完成进度,可直接用 Excel 打开查看与汇报。

> 💡 CSV 文件带 UTF-8 BOM 头,可直接用 Excel 打开,中文显示正常。进度 Excel 则以甘特图形式可视化展示。

## 14. 任务回收站

回收站存放已删除的任务,支持恢复或彻底删除。

### 14.1 进入回收站

点击左侧导航栏 **"回收站"** 进入回收站页面。

### 14.2 查看已删除任务

回收站显示所有已删除的任务,包括:
- 任务标题、描述
- 原所属项目
- 删除时间
- 原负责人

支持搜索过滤,快速定位目标任务。

### 14.3 恢复任务

1. 在回收站中找到目标任务。
2. 点击 **"恢复"** 按钮。
3. 确认后,任务将恢复到原项目中,状态和内容保持不变。

> 💡 恢复后的任务会出现在原项目的看板/列表/甘特图中,其他用户可见。

### 14.4 彻底删除

1. 在回收站中找到目标任务。
2. 点击 **"彻底删除"** 按钮。
3. 确认后,任务将被永久删除,无法恢复。

> ⚠️ 彻底删除不可恢复,请谨慎操作。

### 14.5 清空回收站

目前回收站中的任务需要逐条处理,暂不支持一键清空。

## 16. 高级筛选与全局搜索

### 16.1 高级筛选功能

在项目详情页的工具栏中,点击 **"高级筛选"** 按钮展开筛选面板。

**支持的筛选条件**:
- **状态**:多选筛选任务状态（待办/进行中/审核中/已完成）
- **负责人**:下拉选择指定负责人或"未指派"
- **优先级**:多选筛选优先级（低/中/高/紧急）
- **标签**:多选筛选标签（显示项目中所有标签）
- **开始日期范围**:设置开始日期的起和止
- **截止日期范围**:设置截止日期的起和止
- **关键词**:文本搜索（在高级筛选未启用时也可使用工具栏的搜索框）

**使用方法**:
1. 点击 **"高级筛选"** 按钮展开筛选面板
2. 设置所需的筛选条件
3. 筛选结果实时更新
4. 点击 **"清除筛选"** 重置所有条件

### 16.2 保存筛选方案

**登录用户可保存常用的筛选方案**:

1. 设置好筛选条件后,点击 **"保存方案"** 按钮
2. 输入方案名称（如"我的待办任务"）
3. 保存后可随时加载使用

**管理筛选方案**:
- 点击筛选面板中的方案名称可加载方案
- 鼠标悬停方案名称显示删除按钮

### 16.3 全局搜索

使用全局搜索功能快速跨项目查找任务:

**打开搜索**:
- 点击顶栏的 **搜索图标**,或使用键盘快捷键 `Cmd/Ctrl + K`

**搜索操作**:
- 输入关键词（至少2个字符）
- 系统实时搜索,结果包含任务标题、描述和标签的匹配
- 使用 **上下方向键** 选择搜索结果
- 按 **Enter** 键跳转到任务所在项目并自动打开任务详情

**结果展示**:
- 任务标题高亮显示匹配关键词
- 显示任务所属项目名称
- 显示任务状态和优先级标签

## 23. 常见问题 FAQ

### Q1: 如何重置所有数据?

删除项目根目录下的 `data/app.db` 文件(及 `data/uploads/` 目录),重启系统即可自动重建演示数据。

```bash
rm -f data/app.db
rm -rf data/uploads
npm run dev
```

### Q2: 忘记密码怎么办?

当前版本密码使用 bcrypt 加密存储,无法直接找回。请联系系统管理员:

```bash
# 使用 Node.js 快速重置密码
node -e "
const bcrypt = require('bcrypt');
const hash = bcrypt.hashSync('新密码', 10);
console.log('新密码哈希:', hash);
"
```

然后通过 SQLite 工具更新对应记录的 `password_hash` 字段。

### Q3: 如何添加新的项目成员?

当前版本的成员管理通过"团队"页面 + 项目详情中负责人分配完成:
1. 管理员在登录页注册新用户
2. 在"团队"页面将其角色设置为"团队成员"
3. 在项目详情中创建任务时,将新成员指定为负责人

### Q4: 看板拖拽没有反应怎么办?

- 确认当前账号角色不是"访客"(guest),访客无编辑权限
- 检查是否存在网络延迟,可刷新页面后重试
- 若使用触摸板/触屏,确保 PointerSensor 已正确触发(需要移动 > 5px)

### Q5: 如何导出数据?

系统内置 CSV 导出功能(详见第 13 章):

- **项目列表导出**:在"项目"页点击"导出 CSV"
- **任务列表导出**:在项目详情页点击"导出任务"

如需导出全量原始数据为 JSON,可使用脚本:

```bash
node -e "
const Database = require('better-sqlite3');
const db = new Database('data/app.db');
const tables = ['users','projects','project_members','tasks','comments','subtasks','notifications','templates','attachments'];
const data = {};
tables.forEach(t => data[t] = db.prepare('SELECT * FROM ' + t).all());
require('fs').writeFileSync('export.json', JSON.stringify(data, null, 2));
console.log('已导出到 export.json');
"
```

### Q6: 通知数据存储在哪里?

通知存储在 SQLite 的 `notifications` 表中。系统会在以下场景自动生成通知:
- 任务被分配(assign 类型)
- 任务状态变更(status 类型)
- 收到评论或 @提及(comment 类型)
- 系统提示(system 类型)
- 任务完成(同时触发邮件通知,需配置 SMTP)

### Q7: 邮件通知不生效怎么办?

邮件通知需要配置 SMTP 服务器。请检查:

1. 项目根目录是否创建了 `.env` 文件(可参考 `.env.example`)
2. 是否填写了 `SMTP_HOST`、`SMTP_USER`、`SMTP_PASS` 三个必填项
3. 密码是否为邮箱的 **SMTP 授权码**(非登录密码,QQ/163 等邮箱需单独开启)
4. 端口是否正确:SSL 通常 465,TLS 通常 587
5. 查看后端控制台日志,是否有 `[mail]` 相关错误输出

未配置 SMTP 时系统会打印 `[mail] SMTP 未配置,跳过邮件发送` 警告,属正常行为。

### Q8: 附件上传失败怎么办?

- 单个文件大小不能超过 **20MB**
- 检查 `data/uploads/` 目录是否存在且有写入权限(系统会自动创建)
- 查看浏览器控制台与后端日志的错误信息
- 若附件丢失(文件被手动删除),下载时会提示"文件已丢失"

### Q9: 如何调整任务的完成进度?

在甘特图视图中,有两种方式调整任务进度:

1. **拖拽调整**:将鼠标悬停到任务条右侧边缘,出现拖拽手柄后左右拖动,实时调整完成百分比
2. **直接编辑**:在任务详情抽屉中直接修改进度数值

进度保存后,项目的整体进度会自动重新计算。

### Q10: 甘特图中关键路径如何判断?

系统使用 **CPM(关键路径法)** 算法自动计算:
- 找出所有从开始到结束的最长路径
- 路径上的任务即为关键任务(红色边框标注)
- 关键路径上任何任务的延迟都会直接导致项目延期
- 非关键任务有一定的浮动空间,可在浮动范围内调整而不影响项目工期
