## 1. 快速开始

### 1.1 系统简介

**Atlas** 是一款轻量级的团队项目管理 Web 应用,覆盖"看板与任务面板 / 进度跟踪与统计 / 项目与任务管理 / 团队协作与权限"四大核心模块,内置通知中心和完整的权限体系。

### 1.2 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端 | React 18 · Vite · TailwindCSS · Zustand · dnd-kit · Recharts |
| 后端 | Express 4 · better-sqlite3 · JWT · bcrypt · zod |
| 数据库 | SQLite (本地文件存储 `data/app.db`) |

### 1.3 启动系统

```bash
# 安装依赖(首次运行)
npm install

# 同时启动前端与后端开发服务
npm run dev

# 或者分别启动
npm run server:dev     # 后端 API:http://localhost:3001
npm run client:dev     # 前端 Web:http://localhost:5173
```

打开浏览器访问 `http://localhost:5173` 即可使用。

### 1.4 演示账号

系统内置了以下演示账号(密码均为 `123456`):

| 账号 | 邮箱 | 角色 | 说明 |
| --- | --- | --- | --- |
| 管理员 | `admin@pm.dev` | 系统管理员 | 最高权限,可管理所有成员与角色 |
| 负责人 | `owner@pm.dev` | 项目负责人 | 拥有多个项目 |
| 成员甲 | `member1@pm.dev` | 团队成员 | 参与项目开发 |
| 成员乙 | `member2@pm.dev` | 团队成员 | 参与项目开发 |
| 访客 | `guest@pm.dev` | 访客 | 仅可查看项目信息 |

> ⚠️ 首次启动时,系统会自动创建数据库与演示数据。如需重置,删除 `data/app.db` 后重启即可。

## 2. 登录与账号

### 2.1 登录

1. 打开系统登录页,默认为"登录"标签。
2. 输入邮箱和密码。
3. 点击 **"登录系统"** 按钮进入系统。

### 2.2 注册新账号

1. 在登录页点击顶部 **"注 册"** 标签。
2. 填写昵称、邮箱、密码(密码明文传输,建议使用强密码)。
3. 点击 **"创建账号"** 完成注册。

新注册的账号默认角色为 **团队成员(member)**,由系统管理员在"团队"页面调整权限。

### 2.3 退出登录

点击右上角头像旁的 **退出图标**,即可安全退出当前会话。

## 3. 系统概览 · 仪表板

登录后首先进入仪表板页面,提供全局视角的数据概览。

### 3.1 顶部欢迎区

显示当前用户的昵称首字 + 待办任务数量,点击 **"打开项目"** 可快速跳转至项目列表。

### 3.2 概览卡片

四个核心指标一目了然:

| 卡片 | 说明 |
| --- | --- |
| 进行中项目 | 状态为"进行中"的项目总数 |
| 任务总量 | 所有项目下的任务总数 |
| 已完成项目 | 状态为"已完成"的项目总数 |
| 逾期项目 | 已超过截止日期但未完成的项目数 |

### 3.3 任务状态分布(环形图)

展示四种状态的任务占比:

- 🟣 **待办** (todo)
- 🟡 **进行中** (in_progress)
- 🔵 **审核中** (review)
- 🟢 **已完成** (done)

### 3.4 14 天任务趋势

面积图展示近 14 天"新建任务"与"完成任务"的时间趋势,帮助团队感知节奏变化。

### 3.5 我的待办任务

列出当前用户名下所有未完成任务(最多 8 条),点击可直接跳转到对应项目。

## 4. 项目管理

### 4.1 进入项目列表

点击左侧导航栏 **"项目"** 进入项目列表页。

### 4.2 搜索与筛选

- **搜索框**:按项目名称或描述中的关键词过滤。
- **状态筛选**:切换标签可快速筛选"全部 / 进行中 / 已完成"。

### 4.3 创建新项目

1. 点击右上角 **"新建项目"** 按钮。
2. 在弹窗中填写:
   - **项目名称**(必填)
   - **项目描述**
   - **项目状态**:规划中 / 进行中 / 已完成 / 已归档
   - **截止日期**
3. 提交后,新项目会出现在列表中。

### 4.4 项目卡片

每个项目卡片展示:

- 项目状态徽章
- 项目名称与描述
- **进度条**(自动根据任务完成度计算)
- 项目成员头像堆叠
- 截止日期

点击卡片进入项目详情页。

### 4.5 编辑项目

在项目详情页点击 **"编辑项目"** 按钮,可修改项目信息(名称、描述、状态、截止日期)。

## 5. 项目详情 · 看板与任务

进入项目后,默认显示看板视图。

### 5.1 页面结构

- **顶部区域**:项目名称、状态徽章、描述、进度条、任务数量
- **工具栏**:搜索框 + 视图切换(列表/看板)
- **主区域**:任务展示区

### 5.2 看板视图(默认)

看板将任务按状态分成四列:

| 列名 | 说明 |
| --- | --- |
| 待办 | 尚未开始的任务 |
| 进行中 | 正在执行的任务 |
| 审核中 | 等待审核或验收 |
| 已完成 | 已完成的任务 |

#### 5.2.1 拖拽更新状态

直接用鼠标按住任务卡片,拖拽到目标列,松开即可完成状态更新,系统会自动同步到后端。

> 💡 **小技巧**:鼠标移动超过 5px 才会触发拖拽,避免误操作。

#### 5.2.2 在指定列新建任务

点击某列标题旁的 **"+"** 按钮,会自动将新建任务的预设状态设为该列对应的状态。

#### 5.2.3 看板卡片信息

每张任务卡片显示:
- 任务标题
- 标签 (如有)
- 优先级徽章
- 截止日期(逾期显示红色,即将到期显示黄色)
- 悬停时显示 **编辑** / **删除** 按钮

### 5.3 列表视图

点击工具栏的列表图标切换到表格视图:

- 表格列:任务 | 状态 | 优先级 | 截止 | 操作
- 点击行任意位置 → 打开任务详情抽屉
- 点击行内的编辑/删除图标 → 编辑或删除任务
- 可按状态(全部/待办/进行中/审核中/已完成)快速筛选

### 5.4 新建任务

1. 点击 **"新建任务"** 按钮。
2. 填写任务信息:
   - **任务标题**(必填)
   - **任务描述**
   - **状态**:待办 / 进行中 / 审核中 / 已完成
   - **优先级**:低 / 中 / 高 / 紧急
   - **负责人**:从团队成员中选择
   - **标签**:多个标签,如"设计"、"后端"、"前端"等
   - **截止日期**
3. 提交后,任务会出现在看板或列表中。

### 5.5 编辑与删除任务

- 悬停任务卡片 → 点击 **铅笔图标** 编辑
- 点击 **垃圾桶图标** 编辑
- 列表视图中操作相同

## 6. 任务详情 · 子任务与评论

点击任务卡片/行,右侧弹出 **任务详情抽屉**。

### 6.1 基本信息

- **状态徽章** + **优先级徽章**
- 任务标题、描述
- 截止日期(含逾期/即将到期标记)
- 优先级
- 标签列表

### 6.2 子任务(检查清单)

子任务用于将大任务拆分为可追踪的小步骤。

#### 6.2.1 添加子任务

1. 在"子任务"区域的输入框中输入内容。
2. 按 **回车** 或点击 **"+"** 按钮确认。

#### 6.2.2 完成子任务

点击子任务左侧的 **方框** 即可勾选/取消。完成进度会实时更新:
- 标题旁显示 `(已完成数/总数)`
- 进度条显示完成百分比

#### 6.2.3 删除子任务

鼠标悬停子任务条目,右侧出现 **垃圾桶图标**,点击即可删除。

### 6.3 评论区

#### 6.3.1 查看评论

评论列表按时间顺序展示,包含:
- 评论者头像与昵称
- 评论时间(相对时间,如"5 分钟前")
- 评论内容
- 系统消息以虚线框 + 斜体样式展示(如状态变更记录)

#### 6.3.2 发表评论

在底部输入框填写内容,点击 **"发表评论"** 按钮。

### 6.4 删除任务

在抽屉底部点击 **"删除任务"** 按钮,确认后任务将被永久删除。

## 7. 进度跟踪与统计

点击导航栏 **"统计"** 进入数据统计页面。

### 7.1 时间范围切换

页面右上角可选择统计时间范围:
- **近 14 天**
- **近 30 天**

### 7.2 任务状态分布

与仪表板类似的环形图,展示四种状态的任务数量与占比。

### 7.3 燃尽图

燃尽图用于可视化项目剩余工作量随时间的变化:

- **选择项目**:从下拉菜单选择要查看的项目
- **理想剩余**:灰色虚线,表示按理想进度应剩余的任务量
- **实际剩余**:紫色实线,表示实际剩余的任务量

> 💡 **如何阅读**:实际线低于理想线 → 项目进度超前;实际线高于理想线 → 项目存在延期风险。

### 7.4 成员工作量

横向柱状图展示每位成员的工作负载:

- **总任务**(紫色)
- **进行中**(黄色)
- **已完成**(绿色)

帮助管理员合理分配任务,识别过载或闲置成员。

## 8. 团队协作与权限

点击导航栏 **"团队"** 进入团队管理页面。

### 8.1 角色体系

系统定义了四种角色:

| 角色 | 权限说明 |
| --- | --- |
| **系统管理员** (admin) | 最高权限,可修改所有成员角色、管理所有项目 |
| **项目负责人** (owner) | 管理自己负责的项目,创建与分配任务 |
| **团队成员** (member) | 参与项目,分配和执行任务 |
| **访客** (guest) | 仅查看,不可编辑或创建任务 |

### 8.2 成员信息

每张成员卡片展示:
- 头像与昵称
- 邮箱
- 负责的任务数
- 进行中的任务数
- 当前角色

### 8.3 修改角色

**仅系统管理员可修改角色**:

1. 找到目标成员的卡片。
2. 点击"修改角色"下拉框。
3. 选择新角色后,系统自动保存并提示"角色已更新"。

非管理员看到的下拉框为禁用状态,并显示"仅系统管理员可修改角色"。

## 9. 通知中心

### 9.1 通知入口

### 9.3 标记已读

- **单条标记**:点击通知项右侧的小圆点,标记为已读
- **全部标记**:点击面板顶部的"全部已读"按钮

### 9.4 触发通知的场景

- 你被分配了新任务
- 你负责的任务状态发生变更
- 有人评论了你的任务
- 系统公告或提示

## 11. 数据模型与术语

### 11.1 项目状态

| 状态 | 英文 | 说明 |
| --- | --- | --- |
| 规划中 | planning | 项目尚在规划阶段 |
| 进行中 | active | 项目正在执行 |
| 已完成 | completed | 项目已交付 |
| 已归档 | archived | 项目已归档,不再更新 |

### 11.2 任务状态

| 状态 | 英文 | 颜色 | 说明 |
| --- | --- | --- | --- |
| 待办 | todo | 灰色 | 尚未开始 |
| 进行中 | in_progress | 黄色 | 正在执行 |
| 审核中 | review | 蓝色 | 等待审核验收 |
| 已完成 | done | 绿色 | 已完成 |

### 11.3 任务优先级

| 优先级 | 英文 | 颜色 |
| --- | --- | --- |
| 低 | low | 灰色 |
| 中 | medium | 蓝色 |
| 高 | high | 橙色 |
| 紧急 | urgent | 红色 |

### 11.4 项目成员角色

| 角色 | 说明 |
| --- | --- |
| owner | 项目所有者,拥有全部管理权限 |
| editor | 编辑者,可创建和编辑任务 |
| viewer | 查看者,仅可查看项目内容 |

### 11.5 数据库表结构

系统使用 SQLite 数据库(文件路径 `data/app.db`),包含以下数据表:

| 表名 | 说明 |
| --- | --- |
| `users` | 用户账户信息 |
| `projects` | 项目基本信息 |
| `project_members` | 项目-成员关联(含成员在项目内的角色) |
| `tasks` | 任务主体 |
| `comments` | 任务评论 |
| `subtasks` | 子任务/检查清单 |
| `notifications` | 用户通知 |

## 12. 常见问题 FAQ

### Q1: 如何重置所有数据?

删除项目根目录下的 `data/app.db` 文件,重启系统即可自动重建演示数据。

```bash
rm -f data/app.db
npm run dev
```

### Q2: 忘记密码怎么办?

当前版本密码使用 bcrypt 加密存储,无法直接找回。请联系系统管理员:

```bash
# 使用 Node.js 快速重置密码
node -e "
const bcrypt = require('bcrypt');
const hash = bcrypt.hashSync('新密码', 10);
console.log('新密码哈希:', hash);
"
```

然后通过 SQLite 工具更新对应记录的 `password_hash` 字段。

### Q3: 如何添加新的项目成员?

当前版本的成员管理通过"团队"页面 + 项目详情中负责人分配完成:
1. 管理员在登录页注册新用户
2. 在"团队"页面将其角色设置为"团队成员"
3. 在项目详情中创建任务时,将新成员指定为负责人

### Q4: 看板拖拽没有反应怎么办?

- 确认当前账号角色不是"访客"(guest),访客无编辑权限
- 检查是否存在网络延迟,可刷新页面后重试
- 若使用触摸板/触屏,确保 PointerSensor 已正确触发(需要移动 > 5px)

### Q5: 如何导出数据?

当前版本暂未内置导出功能。可通过以下方式导出:

```bash
# 导出全部数据为 JSON
node -e "
const Database = require('better-sqlite3');
const db = new Database('data/app.db');
const tables = ['users','projects','project_members','tasks','comments','subtasks','notifications'];
const data = {};
tables.forEach(t => data[t] = db.prepare('SELECT * FROM ' + t).all());
require('fs').writeFileSync('export.json', JSON.stringify(data, null, 2));
console.log('已导出到 export.json');
"
```

### Q6: 通知数据存储在哪里?

通知存储在 SQLite 的 `notifications` 表中。系统会在以下场景自动生成通知:
- 任务被分配(assign 类型)
- 任务状态变更(status 类型)
- 收到评论(comment 类型)
- 系统提示(system 类型)

## 13. 部署与运维

### 13.1 生产环境构建

```bash
# 构建前端
npm run build

# 产物位于 dist/ 目录,可部署到任意静态托管服务
```

### 13.2 后端 API

后端为 Express 应用,入口文件:

```
api/index.ts        # 主入口
api/routes/         # 路由模块
api/repository/     # 数据访问层
api/lib/            # 工具库(认证等)
```

启动方式:

```bash
npm run server:dev  # 开发模式(使用 nodemon 热重载)
```

### 13.3 环境变量

在项目根目录创建 `.env` 文件:

```
# JWT 密钥(生产环境务必修改)
JWT_SECRET=your-secret-key-here

# 端口
PORT=3001
```

### 13.4 数据库备份

```bash
# 直接复制数据库文件即可
cp data/app.db data/app.db.backup.$(date +%Y%m%d)
```
