## 1. 快速开始

### 1.1 系统简介

**Atlas** 是一款轻量级的团队项目管理 Web 应用,覆盖"看板与任务面板 / 进度跟踪与统计 / 项目与任务管理 / 团队协作与权限"四大核心模块,内置通知中心和完整的权限体系。

### 1.2 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端 | React 18 · Vite · TailwindCSS · Zustand · dnd-kit · Recharts |
| 后端 | Express 4 · better-sqlite3 · JWT · bcrypt · zod · multer · nodemailer |
| 数据库 | SQLite (本地文件存储 `data/app.db`) |
| 文件存储 | 本地磁盘 `data/uploads/`(任务附件) |

### 1.3 启动系统

```bash
# 安装依赖(首次运行)
npm install

# 同时启动前端与后端开发服务
npm run dev

# 或者分别启动
npm run server:dev     # 后端 API:http://localhost:3001
npm run client:dev     # 前端 Web:http://localhost:5173
```

打开浏览器访问 `http://localhost:5173` 即可使用。

### 1.4 演示账号

系统内置了以下演示账号(密码均为 `123456`):

| 账号 | 邮箱 | 角色 | 说明 |
| --- | --- | --- | --- |
| 管理员 | `admin@pm.dev` | 系统管理员 | 最高权限,可管理所有成员与角色 |
| 负责人 | `owner@pm.dev` | 项目负责人 | 拥有多个项目 |
| 成员甲 | `member1@pm.dev` | 团队成员 | 参与项目开发 |
| 成员乙 | `member2@pm.dev` | 团队成员 | 参与项目开发 |
| 访客 | `guest@pm.dev` | 访客 | 仅可查看项目信息 |

> ⚠️ 首次启动时,系统会自动创建数据库与演示数据。如需重置,删除 `data/app.db` 后重启即可。

## 2. 登录与账号

### 2.1 登录

1. 打开系统登录页,默认为"登录"标签。
2. 输入邮箱和密码。
3. 点击 **"登录系统"** 按钮进入系统。

### 2.2 注册新账号

1. 在登录页点击顶部 **"注 册"** 标签。
2. 填写昵称、邮箱、密码(密码明文传输,建议使用强密码)。
3. 点击 **"创建账号"** 完成注册。

新注册的账号默认角色为 **团队成员(member)**,由系统管理员在"团队"页面调整权限。

### 2.3 退出登录

点击右上角头像旁的 **退出图标**,即可安全退出当前会话。

## 3. 系统概览 · 仪表板

登录后首先进入仪表板页面,提供全局视角的数据概览。

### 3.1 顶部欢迎区

显示当前用户的昵称首字 + 待办任务数量,点击 **"打开项目"** 可快速跳转至项目列表。

### 3.2 概览卡片

四个核心指标一目了然:

| 卡片 | 说明 |
| --- | --- |
| 进行中项目 | 状态为"进行中"的项目总数 |
| 任务总量 | 所有项目下的任务总数 |
| 已完成项目 | 状态为"已完成"的项目总数 |
| 逾期项目 | 已超过截止日期但未完成的项目数 |

### 3.3 任务状态分布(环形图)

展示四种状态的任务占比:

- 🟣 **待办** (todo)
- 🟡 **进行中** (in_progress)
- 🔵 **审核中** (review)
- 🟢 **已完成** (done)

### 3.4 14 天任务趋势

面积图展示近 14 天"新建任务"与"完成任务"的时间趋势,帮助团队感知节奏变化。

### 3.5 我的待办任务

列出当前用户名下所有未完成任务(最多 8 条),点击可直接跳转到对应项目。

## 4. 项目管理

### 4.1 进入项目列表

点击左侧导航栏 **"项目"** 进入项目列表页。

### 4.2 搜索与筛选

- **搜索框**:按项目名称或描述中的关键词过滤。
- **状态筛选**:切换标签可快速筛选"全部 / 进行中 / 已完成"。

### 4.3 创建新项目

1. 点击右上角 **"新建项目"** 按钮。
2. 在弹窗中填写:
   - **项目名称**(必填)
   - **项目描述**
   - **项目状态**:规划中 / 进行中 / 已完成 / 已归档
   - **截止日期**
   - **项目负责人**(仅系统管理员可见):可从团队成员中指定负责人;不选则默认为创建者。指定后,该负责人会自动加入项目成员。
3. 提交后,新项目会出现在列表中。

> 💡 普通成员创建项目时不会看到"负责人"选项,默认自己为负责人。

### 4.4 项目卡片

每个项目卡片展示:

- 项目状态徽章
- 项目名称与描述
- **进度条**(自动根据任务完成度计算)
- 项目成员头像堆叠
- 截止日期

点击卡片进入项目详情页。

### 4.5 编辑项目

在项目详情页点击 **"编辑项目"** 按钮,可修改项目信息(名称、描述、状态、截止日期)。

## 5. 项目详情 · 看板与任务

进入项目后,默认显示看板视图。

### 5.1 页面结构

- **顶部区域**:项目名称、状态徽章、描述、进度条、任务数量
- **操作按钮**:导出任务(CSV)、编辑项目、新建任务
- **工具栏**:搜索框 + 视图切换(列表/看板) + 批量操作入口(列表视图)
- **主区域**:任务展示区

### 5.2 看板视图(默认)

看板将任务按状态分成四列:

| 列名 | 说明 |
| --- | --- |
| 待办 | 尚未开始的任务 |
| 进行中 | 正在执行的任务 |
| 审核中 | 等待审核或验收 |
| 已完成 | 已完成的任务 |

#### 5.2.1 拖拽更新状态

直接用鼠标按住任务卡片,拖拽到目标列,松开即可完成状态更新,系统会自动同步到后端。

> 💡 **小技巧**:鼠标移动超过 5px 才会触发拖拽,避免误操作。

#### 5.2.2 在指定列新建任务

点击某列标题旁的 **"+"** 按钮,会自动将新建任务的预设状态设为该列对应的状态。

#### 5.2.3 看板卡片信息

每张任务卡片显示:
- 任务标题
- 标签 (如有)
- 优先级徽章
- 截止日期(逾期显示红色,即将到期显示黄色)
- 悬停时显示 **编辑** / **删除** 按钮

### 5.3 列表视图

点击工具栏的列表图标切换到表格视图:

- 表格列:选择框 | 任务 | 状态 | 优先级 | 截止 | 操作
- 点击行任意位置 → 打开任务详情抽屉
- 点击行内的编辑/删除图标 → 编辑或删除任务
- 可按状态(全部/待办/进行中/审核中/已完成)快速筛选

#### 5.3.1 批量操作

列表视图支持多选批量操作,大幅提升管理效率:

1. 点击工具栏 **"批量操作"** 按钮进入多选模式。
2. 勾选需要操作的任务(或点击表头全选)。
3. 在底部批量工具栏选择操作:
   - **批量改状态**:一键将选中任务改为待办/进行中/审核中/已完成
   - **批量改负责人**:从下拉菜单选择新负责人
   - **批量删除**:确认后删除所有选中任务
4. 操作完成后显示成功数量,并自动退出多选模式。

> ⚠️ 批量删除不可恢复,请谨慎操作。

### 5.4 新建任务

1. 点击 **"新建任务"** 按钮。
2. 若已有任务模板,对话框顶部会显示 **"从模板创建"** 区域:
   - 从下拉菜单选择模板,自动填充标题、描述、优先级、标签
   - 也可点击模板旁的删除图标移除不再需要的模板
3. 填写任务信息:
   - **任务标题**(必填)
   - **任务描述**
   - **状态**:待办 / 进行中 / 审核中 / 已完成
   - **优先级**:低 / 中 / 高 / 紧急
   - **负责人**:从团队成员中选择
   - **标签**:多个标签,如"设计"、"后端"、"前端"等
   - **截止日期**
4. 提交后,任务会出现在看板或列表中。

> 💡 可在对话框底部点击 **"保存为模板"**,将当前任务配置保存为模板,下次创建任务时快速复用。

### 5.5 编辑与删除任务

- 悬停任务卡片 → 点击 **铅笔图标** 编辑
- 点击 **垃圾桶图标** 编辑
- 列表视图中操作相同

## 6. 任务详情 · 子任务 · 评论 · 附件

点击任务卡片/行,右侧弹出 **任务详情抽屉**。

### 6.1 基本信息

- **状态徽章** + **优先级徽章**
- 任务标题、描述
- 截止日期(含逾期/即将到期标记)
- 优先级
- 标签列表

### 6.2 附件管理

任务支持上传文件附件,方便团队共享资料。

#### 6.2.1 上传附件

1. 在"附件"区域点击 **"上传"** 按钮。
2. 选择一个或多个文件(单个文件最大 20MB)。
3. 上传完成后,附件自动显示在列表中。

> 支持所有文件类型:图片、文档、代码、压缩包等。

#### 6.2.2 查看与下载附件

附件列表显示:
- 文件类型图标(图片/文档/代码等不同样式)
- 原始文件名
- 文件大小、上传者、上传时间
- 点击 **下载图标** 可下载原文件

#### 6.2.3 删除附件

鼠标悬停附件条目,点击右侧的 **垃圾桶图标** 即可删除。上传者本人或系统管理员/项目负责人有权删除。

### 6.3 子任务(检查清单)

子任务用于将大任务拆分为可追踪的小步骤。

#### 6.3.1 添加子任务

1. 在"子任务"区域的输入框中输入内容。
2. 按 **回车** 或点击 **"+"** 按钮确认。

#### 6.3.2 完成子任务

点击子任务左侧的 **方框** 即可勾选/取消。完成进度会实时更新:
- 标题旁显示 `(已完成数/总数)`
- 进度条显示完成百分比

#### 6.3.3 删除子任务

鼠标悬停子任务条目,右侧出现 **垃圾桶图标**,点击即可删除。

### 6.4 评论区

#### 6.4.1 查看评论

评论列表按时间顺序展示,包含:
- 评论者头像与昵称
- 评论时间(相对时间,如"5 分钟前")
- 评论内容
- 系统消息以虚线框 + 斜体样式展示(如状态变更记录)

#### 6.4.2 @提及功能

在评论中可以 @提及团队成员,被提及者会收到通知:

1. 在评论输入框中输入 **`@`** 字符。
2. 系统自动弹出成员选择面板,显示匹配的成员。
3. 使用键盘快捷键操作:
   - **↑ / ↓**:在候选列表中上下选择
   - **Enter / Tab**:确认选择当前成员
   - **Esc**:关闭选择面板
4. 也可以用鼠标点击候选成员。
5. 被提及的用户名会以 `@用户名` 格式插入评论,发表后被提及者收到通知。

> 💡 @提及在评论中会高亮显示为品牌色。

#### 6.4.3 发表评论

在底部输入框填写内容,点击 **"发表评论"** 按钮。系统会自动解析其中的 @提及并通知对应成员。

### 6.5 删除任务

在抽屉底部点击 **"删除任务"** 按钮,确认后任务将被永久删除(关联的附件、评论、子任务一并删除)。

## 7. 任务模板管理

任务模板用于预定义任务的标准配置(标题、描述、优先级、标签),适合重复性工作场景(如 Bug 修复、需求评审、发布流程等),可大幅减少重复输入。

### 7.1 创建模板

有两种方式创建模板:

**方式一:从新建任务对话框保存**
1. 点击"新建任务"打开对话框。
2. 在对话框底部点击 **"保存为模板,下次快速创建"**。
3. 输入模板名称(必填)。
4. 点击 **"保存"** 按钮,当前填写的标题、描述、优先级、标签会被保存为模板。

**方式二:直接填写后保存**
1. 在新建任务对话框中填写所需字段。
2. 点击底部"保存为模板"区域。
3. 输入模板名称并保存。

### 7.2 使用模板创建任务

1. 点击"新建任务"打开对话框。
2. 若已有模板,对话框顶部会显示 **"从模板创建"** 区域。
3. 从下拉菜单选择模板,系统自动填充:
   - 任务标题
   - 任务描述
   - 优先级
   - 标签
4. 可在填充基础上继续修改,补充负责人、截止日期等信息。
5. 提交保存即可。

### 7.3 删除模板

1. 在新建任务对话框的"从模板创建"区域选择要删除的模板。
2. 点击模板下拉框旁的 **垃圾桶图标**。
3. 确认后模板被删除(已用该模板创建的任务不受影响)。

> 💡 模板对所有用户共享,任何登录用户都可创建和使用模板。

## 8. 进度跟踪与统计

点击导航栏 **"统计"** 进入数据统计页面。

### 8.1 时间范围切换

页面右上角可选择统计时间范围:
- **近 14 天**
- **近 30 天**

### 8.2 任务状态分布

与仪表板类似的环形图,展示四种状态的任务数量与占比。

### 8.3 燃尽图

燃尽图用于可视化项目剩余工作量随时间的变化:

- **选择项目**:从下拉菜单选择要查看的项目
- **理想剩余**:灰色虚线,表示按理想进度应剩余的任务量
- **实际剩余**:紫色实线,表示实际剩余的任务量

> 💡 **如何阅读**:实际线低于理想线 → 项目进度超前;实际线高于理想线 → 项目存在延期风险。

### 8.4 成员工作量

横向柱状图展示每位成员的工作负载:

- **总任务**(紫色)
- **进行中**(黄色)
- **已完成**(绿色)

帮助管理员合理分配任务,识别过载或闲置成员。

## 9. 团队协作与权限

点击导航栏 **"团队"** 进入团队管理页面。

### 9.1 角色体系

系统定义了四种角色:

| 角色 | 权限说明 |
| --- | --- |
| **系统管理员** (admin) | 最高权限,可修改所有成员角色、管理所有项目、创建项目时指定负责人 |
| **项目负责人** (owner) | 管理自己负责的项目,创建与分配任务 |
| **团队成员** (member) | 参与项目,分配和执行任务 |
| **访客** (guest) | 仅查看,不可编辑或创建任务 |

### 9.2 成员信息

每张成员卡片展示:
- 头像与昵称
- 邮箱
- 负责的任务数
- 进行中的任务数
- 当前角色

### 9.3 修改角色

**仅系统管理员可修改角色**:

1. 找到目标成员的卡片。
2. 点击"修改角色"下拉框。
3. 选择新角色后,系统自动保存并提示"角色已更新"。

非管理员看到的下拉框为禁用状态,并显示"仅系统管理员可修改角色"。

## 10. 通知中心 · 邮件通知

### 10.1 通知入口

顶栏右侧的 **铃铛图标**,带红色徽章显示未读数量。点击铃铛可打开下拉面板快速查看;点击"查看全部"可进入 **通知历史页**。

### 10.2 通知下拉面板(快捷查看)

点击铃铛图标打开下拉面板,展示最近通知:

- 通知类型:分配任务、状态变更、评论(@提及)、系统消息
- 通知标题与正文
- 已读 / 未读状态(未读加粗显示)
- 点击单条通知可标记已读并跳转至关联项目

### 10.3 通知历史页(完整记录)

点击下拉面板中的"查看全部"或直接访问 `/notifications` 进入独立的通知历史页,功能包括:

- **类型筛选**:顶部标签切换"全部 / 分配 / 状态 / 评论 / 系统",每个标签显示对应数量
- **批量操作**:"全部已读"一键标记所有未读通知
- **单条操作**:标记已读、删除通知
- **跳转**:点击通知项可跳转到关联的项目或任务

### 10.4 标记已读

- **单条标记**:点击通知项右侧的对勾图标
- **全部标记**:点击"全部已读"按钮

### 10.5 删除通知

在通知历史页,鼠标悬停通知项,点击右侧的 **垃圾桶图标** 即可删除。

### 10.6 邮件通知

当任务状态变更为 **"已完成"** 时,系统会自动给任务负责人发送邮件通知(需配置 SMTP)。

- 邮件内容包含:项目名称、任务标题、完成提醒
- 采用精美 HTML 模板,品牌色渐变头部
- 仅当负责人不是操作者本人时发送
- 未配置 SMTP 时自动跳过,不影响系统其他功能

> 💡 邮件配置详见 [15.4 邮件配置](#154-邮件配置-smtp)。

### 10.7 触发通知的场景

| 场景 | 通知类型 | 接收者 |
| --- | --- | --- |
| 你被分配新任务 | assign | 新负责人 |
| 你被解除分配 | assign | 原负责人 |
| 任务状态变更 | status | 任务负责人 |
| 任务被评论 | comment | 任务负责人 |
| 评论中 @提及你 | comment | 被提及者 |
| 任务完成 | 邮件 + 站内 | 任务负责人 |
| 系统公告 | system | 相关用户 |

## 14. 常见问题 FAQ

### Q1: 如何重置所有数据?

删除项目根目录下的 `data/app.db` 文件(及 `data/uploads/` 目录),重启系统即可自动重建演示数据。

```bash
rm -f data/app.db
rm -rf data/uploads
npm run dev
```

### Q2: 忘记密码怎么办?

当前版本密码使用 bcrypt 加密存储,无法直接找回。请联系系统管理员:

```bash
# 使用 Node.js 快速重置密码
node -e "
const bcrypt = require('bcrypt');
const hash = bcrypt.hashSync('新密码', 10);
console.log('新密码哈希:', hash);
"
```

然后通过 SQLite 工具更新对应记录的 `password_hash` 字段。

### Q3: 如何添加新的项目成员?

当前版本的成员管理通过"团队"页面 + 项目详情中负责人分配完成:
1. 管理员在登录页注册新用户
2. 在"团队"页面将其角色设置为"团队成员"
3. 在项目详情中创建任务时,将新成员指定为负责人

### Q4: 看板拖拽没有反应怎么办?

- 确认当前账号角色不是"访客"(guest),访客无编辑权限
- 检查是否存在网络延迟,可刷新页面后重试
- 若使用触摸板/触屏,确保 PointerSensor 已正确触发(需要移动 > 5px)

### Q5: 如何导出数据?

系统内置 CSV 导出功能(详见第 11 章):

- **项目列表导出**:在"项目"页点击"导出 CSV"
- **任务列表导出**:在项目详情页点击"导出任务"

如需导出全量原始数据为 JSON,可使用脚本:

```bash
node -e "
const Database = require('better-sqlite3');
const db = new Database('data/app.db');
const tables = ['users','projects','project_members','tasks','comments','subtasks','notifications','templates','attachments'];
const data = {};
tables.forEach(t => data[t] = db.prepare('SELECT * FROM ' + t).all());
require('fs').writeFileSync('export.json', JSON.stringify(data, null, 2));
console.log('已导出到 export.json');
"
```

### Q6: 通知数据存储在哪里?

通知存储在 SQLite 的 `notifications` 表中。系统会在以下场景自动生成通知:
- 任务被分配(assign 类型)
- 任务状态变更(status 类型)
- 收到评论或 @提及(comment 类型)
- 系统提示(system 类型)
- 任务完成(同时触发邮件通知,需配置 SMTP)

### Q7: 邮件通知不生效怎么办?

邮件通知需要配置 SMTP 服务器。请检查:

1. 项目根目录是否创建了 `.env` 文件(可参考 `.env.example`)
2. 是否填写了 `SMTP_HOST`、`SMTP_USER`、`SMTP_PASS` 三个必填项
3. 密码是否为邮箱的 **SMTP 授权码**(非登录密码,QQ/163 等邮箱需单独开启)
4. 端口是否正确:SSL 通常 465,TLS 通常 587
5. 查看后端控制台日志,是否有 `[mail]` 相关错误输出

未配置 SMTP 时系统会打印 `[mail] SMTP 未配置,跳过邮件发送` 警告,属正常行为。

### Q8: 附件上传失败怎么办?

- 单个文件大小不能超过 **20MB**
- 检查 `data/uploads/` 目录是否存在且有写入权限(系统会自动创建)
- 查看浏览器控制台与后端日志的错误信息
- 若附件丢失(文件被手动删除),下载时会提示"文件已丢失"

```
# JWT 密钥(生产环境务必修改)
JWT_SECRET=your-secret-key-here

# 端口
PORT=3001
```

### 15.4 邮件配置 (SMTP)

任务完成邮件通知需要配置 SMTP,在 `.env` 文件中添加:

```
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=your-email@qq.com
SMTP_PASS=your-smtp-auth-code
SMTP_FROM=Atlas <your-email@qq.com>
```

**常见邮箱 SMTP 参考**:

| 邮箱 | SMTP 主机 | 端口 | 说明 |
| --- | --- | --- | --- |
| QQ 邮箱 | smtp.qq.com | 465 | 需开启 SMTP,使用授权码 |
| 163 邮箱 | smtp.163.com | 465 | 需开启 SMTP,使用授权码 |
| Gmail | smtp.gmail.com | 587 | 需使用应用专用密码 |
| Outlook | smtp.office365.com | 587 | 使用账号密码 |

> ⚠️ 密码字段填写的是邮箱的 **SMTP 授权码**,而非登录密码。各大邮箱一般在"设置 → 账户"中开启 SMTP 服务后生成。
