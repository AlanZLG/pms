## 2. Bug 修复验证

### BUG-001: 新建项目对话框无法关闭

| 项目 | 详情 |
|------|------|
| **严重程度** | 高 — 阻塞核心功能 |
| **影响范围** | 所有用户创建/编辑项目场景 |
| **根因** | [ProjectDialog.tsx](file:///Volumes/DATA/Project/src/components/ProjectDialog.tsx) 组件缺少 `if (!open) return null` 条件渲染判断，`open` 变为 `false` 后组件仍被渲染 |
| **修复方案** | 添加条件渲染 + ESC 键支持 |
| **修复提交** | `2c3d77c` |

**验证结果**：

| 关闭方式 | 预期 | 实际 | 状态 |
|----------|------|------|------|
| 点击右上角 ✕ 按钮 | 对话框消失 | 对话框消失 | ✅ 通过 |
| 点击"取消"按钮 | 对话框消失 | 对话框消失 | ✅ 通过 |
| 点击黑色遮罩背景 | 对话框消失 | 对话框消失 | ✅ 通过 |
| 按 ESC 键 | 对话框消失 | 对话框消失 | ✅ 通过 |

### BUG-002: 创建项目报错 "7 values for 8 columns"

| 项目 | 详情 |
|------|------|
| **严重程度** | 高 — 完全阻塞项目创建 |
| **影响范围** | 所有用户，创建项目接口完全不可用 |
| **根因** | [repo.ts:72](file:///Volumes/DATA/Project/api/repository/repo.ts#L72) INSERT 语句 8 列对应 7 个占位符（`progress` 列硬编码为 0 但未占占位符） |
| **修复方案** | 改为 8 个占位符，`progress` 值正常通过 `.run()` 传入 |
| **修复提交** | `2c3d77c` |

**验证结果**：

```
POST /api/projects
Body: {"name":"测试项目","status":"planning"}
Response: 201 Created
{
  "project": {
    "id": "4b36a06b-...",
    "name": "测试项目",
    "progress": 0,
    "members": [{"userId": "...", "role": "owner"}]
  }
}
```

## 8. 已知限制

| # | 限制项 | 说明 | 影响 |
|---|--------|------|------|
| 1 | 邮件通知依赖 SMTP | 未配置 SMTP 时自动跳过邮件发送 | 不影响核心功能，任务完成不会发邮件 |
| 2 | 附件无预览 | 图片附件暂不支持在线预览 | 需下载后查看 |
| 3 | 通知为轮询模式 | 当前通过页面加载时拉取通知，非实时推送 | 新通知需刷新页面/切换页面才能看到 |
| 4 | 密码不可自助修改 | 需联系管理员在数据库中重置 | 不便但安全 |
| 5 | 无单元测试 | 当前仅有集成测试和手动测试 | 需在 v1.2+ 补充单元测试覆盖 |
