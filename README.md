## ✨ 功能特性

### 核心模块
- **看板视图** - 四列看板（待办 / 进行中 / 审核中 / 已完成），拖拽更新状态
- **甘特图视图** - 时间线可视化，任务条拖拽调整、依赖线（FS/SS/FF/SF）、关键路径高亮、进度拖拽
- **列表视图** - 表格展示，支持多状态筛选与批量操作
- **任务管理** - 任务 CRUD、优先级、标签、截止日期、负责人指派、进度百分比
- **子任务/检查清单** - 将大任务拆分为可追踪的小步骤
- **评论系统** - 任务级评论 + 系统流水记录 + 操作历史自动记录

### 协作增强 (v1.1)
- **@提及** - 评论中 @成员自动补全，被提及者收到通知
- **任务模板** - 预定义任务模板，一键创建，支持保存为模板
- **任务附件** - 上传/下载/删除文件附件（最大 20MB）
- **批量操作** - 多选任务批量改状态、改负责人、删除
- **通知中心** - 下拉快捷查看 + 独立历史页，支持类型筛选
- **邮件通知** - 任务完成自动发送邮件（Nodemailer + SMTP）

### 甘特图增强 (v1.1)
- **时间线视图** - 日/周/月三级缩放，键盘 `+/-` 快速调整
- **进度拖拽** - 悬停任务条边缘拖拽，实时调整完成百分比
- **依赖关系** - SVG 贝塞尔曲线连接，支持 FS/SS/FF/SF 四种类型
- **关键路径** - CPM 算法自动计算，红色边框高亮关键任务
- **泳道分组** - 按负责人分组，可折叠/展开
- **键盘快捷键** - `+/-` 缩放、`D` 回到今天、`G` 切换分组、`Esc` 取消
- **任务搜索** - 工具栏搜索框实时过滤

### 数据与统计
- **CSV 导出** - 项目列表与项目任务导出为 CSV（UTF-8 BOM）
- **进度 Excel** - 甘特图格式的进度导出（ExcelJS）
- **数据统计** - 任务状态分布、14天趋势、燃尽图、成员工作量；统计页 7/14/30 天全指标联动
- **项目管理** - 项目 CRUD、进度自动计算、创建时指定负责人
- **操作历史** - 任务变更（状态/负责人/进度/日期）自动记录

### 权限体系
- **五级角色** - 系统管理员 / 项目核算人员 / 项目负责人 / 团队成员 / 访客
- **JWT 鉴权** - 安全登录与会话管理
- **数据隔离** - 按角色过滤可见数据
- **数据可见范围 (v1.5)** - 除系统管理员外，所有用户仅能查看自己参与项目的统计数据（仪表板/统计/工时报表/运维台账），越权访问返回空集而非报错
- **团队页权限分级 (v1.5)** - 侧边栏入口按 team.view 权限过滤；无权限者接口仅返回协作最小字段（供负责人下拉），不外泄邮箱与任务统计
- **预算审批** - 预算需管理员或项目核算审批方可生效

### 项目核算与预算 (v1.2)
- **预算管理** - 项目预算 CRUD，支持人工/外包/硬件/软件/其他五类预算
- **预算审批** - 待审批/已批准/已驳回状态，仅管理员和项目核算可审批
- **支出登记** - 按预算类别登记支出，实时监控预算使用
- **成本统计** - 项目成本汇总，预算 vs 支出对比
- **成员成本** - 时薪设置、外包标记、成本中心分类；未设置时按回退链取价：类别时薪 → 项目角色默认价（负责人 200/成员 150/外包 125）

### 工时管理 (v1.2, v1.5 增强)
- **任务工时** - 每个任务可登记计划工时/内部实际/计费工时与日期
- **工时报表** - 任务计划工时与登记工时双口径汇总、按项目/人员/日期筛选、工时偏差分析、趋势图叠加任务计划基线；矩阵/明细/成本区块卡内滚动（sticky 表头与人员列）
- **成本核算** - 根据时薪自动计算项目成本，时薪回退链：个人 → 类别 → 项目角色默认价（按项目内实际角色动态取价）→ 0

### 项目治理与数据安全 (v1.4, v1.5 增强)
- **项目删除审批** - 项目负责人删除项目需管理员或项目核算人员审批；管理员可直接删除
- **驳回原因** - 审批驳回可填写原因（≤200 字），实时校验提示
- **审批通知** - 批准/驳回均通过站内通知告知申请人，项目卡片展示驳回原因
- **回收站审批入口 (v1.5)** - 管理员/项目核算可在回收站直接批准或驳回删除申请
- **每日自动备份** - 02:30 自动在线备份数据库（gzip 压缩，保留 30 天）
- **手动备份脚本** - `scripts/backup-db.sh`，基于 SQLite 在线备份协议

### 系统增强 (v1.2)
- **暗黑/亮色主题** - 一键切换主题，偏好保存至 localStorage
- **任务回收站** - 软删除机制，支持恢复与彻底删除
- **项目回收站** - 项目删除同样进入回收站，可随时恢复
- **数据库备份** - 一键导出/导入 SQLite 数据库
- **飞书集成** - 绑定飞书账号，支持 OAuth 授权
- **个人设置** - 修改昵称、查看账户信息

### 智能搜索与筛选 (v1.3)
- **高级筛选** - 多条件组合筛选（状态/负责人/优先级/标签/日期范围）
- **筛选方案** - 保存/加载/删除常用筛选方案
- **全局搜索** - Cmd/Ctrl + K 快捷键，跨项目搜索任务
- **结果高亮** - 搜索结果关键词高亮显示
- **键盘导航** - 搜索结果支持上下键选择，回车跳转

### 看板与项目增强 (v1.3)
- **自定义看板列** - 管理员可添加/重命名/删除/排序看板列
- **列颜色配置** - 每个列可自定义颜色
- **项目模板** - 创建项目时可选模板（网站开发/产品迭代/客户支持），按分类分组（v1.8.6：运维/开发/咨询/实施 + 产品迭代，选模板自动预填项目类型）
- **模板管理** - 管理员可创建/编辑/删除自定义模板
- **从项目保存模板** - 将现有项目配置保存为模板
- **批量导入成员** - CSV/Excel 文件批量导入项目成员

### 权限与角色增强 (v1.3)
- **自定义角色** - 创建自定义角色，配置细粒度权限
- **权限矩阵** - 40 项权限点，按 9 大分类分组配置
- **角色管理** - 管理员可创建/编辑/删除自定义角色
- **系统角色** - 5 个系统预设角色，存量库启动时自动补齐新权限

### 甘特图增强 (v1.3)
- **拖拽创建依赖** - 从任务条拖拽到另一任务创建依赖关系
- **依赖类型编辑** - 双击依赖线编辑类型和延迟天数
- **颜色区分** - 四种依赖类型不同颜色（FS蓝/SS绿/FF橙/SF红）
- **依赖标签** - 依赖线显示类型标签和延迟天数

### 运维台账/课题表与 AI 经验分析 (v1.6)
- **运维台账/课题表 (v1.8.4 更名)** - 13 固定字段 + 自定义扩展字段，按项目隔离，Excel 导入/导出，月份×分类统计，任务转台账溯源；同一套表双用途：运维项目登记台账，开发实施项目记录课题
- **AI 经验分析** - 配置任意 OpenAI 兼容 LLM（含本地 vLLM/Ollama）后，按当前问题召回已闭环台账的相似案例，流式（SSE）生成原因分析/建议步骤/风险提示；相似案例可点击直达台账详情
- **语义召回（可选）** - 配置 `LLM_EMBED_MODEL` 后叠加向量余弦重排（向量按台账缓存，自动失效重建），不同措辞的相似经验也能召回；embedding 异常静默降级为关键词排序
- **阅读体验** - 问题/解决方案列定宽展示，长文本点击展开/收起、一键复制；无编辑权限用户可只读查看台账详情
- **AI 排障助手 (v1.7)** - 台账页对话式问答：多轮流式对话，每轮自动检索台账相似案例注入上下文，参考案例卡片点击直达台账详情；支持停止生成与多轮追问

### 项目类型 (v1.8.5，v1.8.7 扩为五类)
- **五类型必选** - 新建项目时首先选择项目类型：运维项目/开发项目/咨询项目/实施项目/产品迭代（按钮组，未选不放行）；后端强校验，编辑可修改
- **类型徽章** - 项目卡片与详情标题展示五色类型徽章（历史未设置类型的项目不显示）
- **台账入口动态命名** - 项目详情内嵌面板按类型显示：运维项目显示「运维台账」，其余类型显示「课题表」
- **存量回填 (v1.8.7)** - 现有有效项目已按实际用途补设类型

## 🚀 快速开始

### 环境要求

- Node.js >= 18
- npm

### 安装与启动

```bash
# 克隆仓库
git clone https://github.com/AlanZLG/pms.git
cd pms

# 安装依赖
npm install

# 同时启动前后端开发服务（推荐）
npm run dev

# 或分别启动
npm run server:dev    # 后端 API: http://localhost:3001
npm run client:dev    # 前端 Web: http://localhost:5173
```

打开浏览器访问 http://localhost:5173 即可使用。

### 生产构建

```bash
npm run build
```

产物位于 `dist/` 目录，可部署到任意静态托管服务。

## ⚙️ 环境变量

复制 `.env.example` 为 `.env` 并按需配置：

```bash
cp .env.example .env
```

```env
# 服务端口
PORT=3001

# JWT 密钥（生产环境务必修改）
JWT_SECRET=pm-dev-secret-change-me

# 邮件通知（可选，未配置则跳过邮件）
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=your-email@qq.com
SMTP_PASS=your-smtp-auth-code
SMTP_FROM=Atlas <your-email@qq.com>

# AI 经验分析（可选，任意 OpenAI 兼容服务；未配置时台账「AI 分析」入口隐藏）
LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
LLM_API_KEY=your-api-key
LLM_CHAT_MODEL=doubao-seed-1-6
LLM_TIMEOUT_MS=60000

# AI 语义召回（可选，embedding 重排；BASE_URL/API_KEY 未配置时回落到上面的 LLM_*）
# LLM_EMBED_MODEL=doubao-embedding
```

> 邮件配置参考 `.env.example` 中的常见邮箱 SMTP 配置表。

## 🗺️ 演进路线

- ✅ **v1.0** - 四大核心模块、用户认证、通知中心、子任务
- ✅ **v1.1** - 批量操作、@提及、任务模板、任务附件、邮件通知、CSV 导出、甘特图、进度拖拽、操作历史、代码分割
- ✅ **v1.2** - 暗黑/亮色主题、任务回收站、数据库备份/恢复、预算管理（含审批）、支出登记、工时管理、飞书集成、成员成本、个人设置
- ✅ **v1.3** - 高级筛选、全局搜索、自定义看板列、项目模板、自定义角色、甘特图拖拽依赖、成员批量导入
- ✅ **v1.4** - 项目删除审批流（驳回原因 + 站内通知）、权限点扩充至 40 项、每日自动数据库备份
- ✅ **v1.5** - 数据权限隔离（项目集合作用域）、工时报表整改（任务计划工时/登记工时双口径、偏差分析、趋势基线、期间/项目默认值、项目-人员联动、历史参与人）、登记计划工时字段、回收站删除审批入口、成本汇总 SQL 修复、团队页权限分级（team.view）、甘特图日期闭区间修复
- ✅ **v1.6** - 统计页 7/14/30 天全指标联动（状态分布按 updated_at 窗口、燃尽图时间窗口切片、成员工作量 updatedAt 口径 + 滚动，仪表板保持全量）、工时报表长列表滚动布局（矩阵双向滚动 sticky 表头/人员列/合计行、区块卡内滚动、等高对齐修复）、成员成本默认时薪回退链（项目角色动态价：负责人 200/成员 150/外包 125）、运维台账 AI 经验分析（相似案例召回 + SSE 流式输出 + 非流式降级）、可选 embedding 语义召回重排（向量缓存表）、问题/解决方案列展开与复制、台账只读详情视图、案例点击跳转
- ✅ **v1.7** - AI 排障助手（台账页对话式排障：chat-stream 多轮 SSE 流式、案例卡片溯源、停止生成；无状态会话）、修复 SSE 客户端断开检测误杀（req→res close）、chatStream 空闲超时语义、召回分词修复（Intl.Segmenter 词典分词，自然语言提问不再召回恒空）
- ✅ **v1.8** - 运维台账数据作用域隔离（非管理者仅见创建/参与项目的台账，覆盖全部台账端点，越权读写 403/404、越权查询空集防枚举；AI 案例召回不隔离、跨项目卡片点击有提示）、导入查重预检弹窗（v1.8.1）、已完成台账经验字段必填（v1.8.2）、台账必须关联项目（v1.8.3：移除「未关联」视图，新建/导入强制选择所属项目，内部作业统一归集到项目名下）、功能更名「运维台账/课题表」（v1.8.4：运维项目登记台账，开发实施项目记录课题）
- ✅ **v1.8.5** - 项目类型（新建项目必选运维/开发/咨询/实施四类型，后端强校验；四色类型徽章；台账入口按类型动态命名——运维项目「运维台账」、其余「课题表」）
- ✅ **v1.8.6** - 模板分类（模板分五类：运维/开发/咨询/实施 + 产品迭代；创建/编辑模板必选分类，创建项目选模板自动预填项目类型，下拉按分类分组，存为模板自动带分类）
- ✅ **v1.8.7** - 项目类型扩为五类（新增「产品迭代」正式类型，模板分类同名一一对应；存量有效项目按实际用途回填类型）
- ✅ **v1.8.8** - 系统模板新增「咨询服务模板」（咨询项目类，六阶段流程，存量库启动自动补插）
- ✅ **v1.8.9** - 系统模板新增「实施交付模板」（实施项目类，七阶段流程）——至此五类项目类型均有对应系统模板
- ✅ **v1.9.0** - 项目类型扩为六类（新增「运维增强」：基于现有系统的追加/改善开发，归运维台账）+ 结项一键合并到运维项目（台账记录批量转绑、工时归集、已合并标记）
- 🔜 **v1.9+** - 富文本评论、实时协作、移动端适配、自定义工作流
