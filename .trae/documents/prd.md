## 1. 产品概述

本项目是一款面向中小型团队的 Web 端项目管理系统,旨在通过看板视图、任务追踪和数据可视化,帮助团队高效组织协作、掌握项目进度、明确权责分工。
- 解决团队在项目管理中任务分配不清、进度不可见、协作沟通混乱等问题
- 目标用户为软件开发团队、产品团队及跨职能协作小组,核心价值在于以清晰直观的可视化方式驱动项目交付

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------------------|------------------|
| 系统管理员 | 预置账号 | 管理项目与成员、分配角色、配置系统 |
| 项目负责人 | 邀请加入 | 创建项目、分配任务、管理看板、查看全部统计 |
| 团队成员 | 邀请加入 | 查看所属项目、领取及更新任务、评论协作 |
| 访客 | 邀请(只读) | 查看指定项目看板与进度,不可编辑 |

### 2.2 功能模块

1. **仪表板首页**:项目概览、今日任务、进度概览、数据图表
2. **项目与任务管理**:项目列表、项目详情、任务创建/编辑/分配
3. **看板与任务面板**:拖拽式看板、多状态列、任务卡片
4. **进度跟踪与统计**:进度图表、燃尽图、成员工作量分析
5. **团队协作与权限**:成员管理、角色权限、任务评论与通知

| 页面名称 | 模块名称 | 功能描述 |

## 3. 核心流程

**主要用户流程:**
1. 用户登录后进入仪表板,查看自己的概览与今日任务
2. 进入项目列表,创建或进入某个项目
3. 在项目详情中创建任务并分配给团队成员,设置优先级与截止日
4. 切换至看板视图,拖拽任务卡片在不同状态列之间流转
5. 团队成员更新任务进度,发表评论,系统统计模块自动汇总
6. 负责人通过统计页面查看燃尽图、工作量与完成率,调整项目计划

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 采用深蓝灰(#0F172A)作为背景,辅以靛蓝(#6366F1)作为主强调色,搭配柔和的薄荷绿(#10B981)表示完成、琥珀色(#F59E0B)表示进行中、珊瑚红(#EF4444)表示逾期
- **按钮风格**: 圆角(8px)按钮,主按钮使用靛蓝渐变,次按钮使用透明边框,带轻微阴影与悬停动效
- **字体**: 标题使用 "Bricolage Grotesque"(可变字重),正文使用 "Space Grotesk",数字使用 "JetBrains Mono"
- **布局风格**: 左侧固定侧边栏 + 顶部导航栏 + 卡片式主内容区,面板间使用疏密有致的留白
- **图标风格**: 线性图标风格,搭配少量微动效,避免装饰过度

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 仪表板 | 项目概览卡片 | 圆角卡片、渐变底色、数字突出、入场动画 |
| 仪表板 | 今日任务列表 | 左侧优先级色条 + 复选框 + 标题 + 截止标签 |
| 仪表板 | 进度图表 | 环形图中心动画数字 + 渐变环,柱状图带悬浮提示 |
| 项目列表 | 项目卡片 | 网格布局,顶部进度条,底部成员头像堆叠 |
| 项目详情 | 视图切换 | 顶部 Tab 切换(列表/看板),带下划线滑动指示 |
| 看板面板 | 拖拽列 | 4 列等宽布局,列头顶部圆点指示状态,拖拽阴影 |

| 登录/注册 | 认证表单 | 左侧品牌插画风插画 + 右侧玻璃拟态表单卡 |

### 4.3 响应式

- 桌面优先设计,断点划分:
  - ≥1200px: 完整双栏 / 三栏布局
  - 768-1199px: 看板列自动折行,侧栏可折叠
  - <768px: 单列布局,看板转为横向滑动,侧栏抽屉式
- 移动端触摸优化: 按钮最小点击区 44px,拖拽改为长按触发状态切换菜单
